# Factorial Program in Python

## 📌 Description

This is a simple Python program that calculates the **factorial of a given number**.

The factorial of a non-negative integer `n` is the product of all positive integers from `1` to `n`.

For example:

`5! = 5 × 4 × 3 × 2 × 1 = 120`

## 🚀 Features

* Takes a number as input from the user.
* Checks if the number is negative.
* Calculates the factorial using a loop.
* Displays the result.

## 🛠️ Technologies Used

* **Python 3**

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the program:

```bash
python factorial.py
```

5. Enter a number when prompted.

## 💻 Example

```text
Enter a number: 5
The factorial of 5 is 120
```
